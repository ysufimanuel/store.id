ERP Mini — POS + Finance + Logistik + E-Commerce

Proyek ini adalah aplikasi Next.js + Supabase yang perlu di-build dan dijalankan sebagai server (bukan file statis).

Cara menjalankan

  1. Buat project Supabase, jalankan supabase/schema.sql di SQL Editor
  2. Isi .env.local (lihat .env.example)
  3. npm install && npm run dev, atau deploy ke Vercel / Docker

Panduan lengkap ada di README.md.
